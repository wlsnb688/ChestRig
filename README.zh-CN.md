# Chest Rig / 胸挂

Chest Rig 是一个 **Minecraft 1.21.1 / NeoForge** 模组，把实用的胸挂直接整合到原版胸甲上。武器、箭矢、食物和通用储物槽都属于胸甲本身，不需要额外合成或携带“胸挂”物品。

## 环境要求

| 项目 | 版本 |
| --- | --- |
| Minecraft | 1.21.1 |
| NeoForge | 21.1.267 或更新的 21.1.x |
| Java | 21 |
| 可选 | AppleSkin：低生命自动进食与营养值显示 |

客户端和服务端都要安装。模组与 **Inventory HUD+** 互斥，启动前请移除它。

## 安装

1. 安装 Minecraft 1.21.1 对应的 NeoForge 21.1.267。
2. 把 `chest_rig-1.21.1-neoforge-21.1.267-0.1.0-Alpha.jar` 放进客户端和服务端的 `mods` 文件夹。
3. 如果装有 Inventory HUD+，先移除。
4. 启动游戏，穿上胸甲即可，不需要额外物品或配方。

## 快速开始

穿着胸甲打开生存模式背包，底部会出现九个胸挂槽位；只有当前胸甲材质解锁的槽位可用。

| 胸甲 | 武器槽 | 箭矢槽 | 食物槽 | 通用槽 |
| --- | ---: | ---: | ---: | ---: |
| 皮革 | 1 | 1 | 0 | 0 |
| 锁链 | 1 | 2 | 1 | 0 |
| 铁 | 2 | 3 | 1 | 0 |
| 金 | 2 | 3 | 4 | 0 |
| 钻石 | 2 | 4 | 3 | 0 |
| 下界合金 | 2 | 4 | 2 | 1 |

- **武器槽**接受弓、弩、剑、斧和三叉戟。
- **箭矢槽**接受箭矢，包括模组箭矢。
- **食物槽**接受带有食物组件的物品。
- **通用槽**接受任何物品，只有下界合金胸甲拥有。

胸挂内容属于胸甲本身，取下或丢出胸甲时不会散落。悬停胸甲可以像潜影盒一样查看内容物。钻石胸甲升级为下界合金时会保留内容物、名称和附魔。

## 操作

| 操作 | 默认按键 |
| --- | --- |
| 选中 / 放下胸挂武器 | `G` |
| 选中期间切换武器槽 | 滚轮或副手交换键 |
| 持弓/弩潜行时切换弹药 | 滚轮 |
| 上一个 / 下一个弹药槽 | 鼠标侧键 5 / 4 |
| 重置弹药选择 | 鼠标中键 |
| 打开 HUD 设置 | `O` |
| 把箭矢、剑或斧存入胸挂 | 右键点击物品 |

所有按键都可以在 **选项 -> 控制 -> Chest Rig** 中重新绑定。

## 弹药与胸挂武器

- 持弓或弩并真正潜行时打开弹药 HUD。列表先显示胸挂箭矢槽，再显示副手、快捷栏和主背包中的有效箭矢。
- 滚动滚轮切换弹药，鼠标侧键 5 / 4 选择上一个 / 下一个槽位，鼠标中键把武器重置到默认槽。
- 武器在背包期间会记住自己的弹药选择；丢出、放进容器或未开启 keepInventory 死亡会清除选择。
- 按 `G` 选中或放下胸挂武器；选中期间滚动滚轮或按副手交换键切换胸挂武器槽。
- 快捷栏右侧的槽位在未装备胸甲或没有武器时隐藏，选中时显示白色框线。
- 从胸挂掷出的三叉戟会从胸挂移除、落地发光，并在拾取后回到原槽位或其他空武器槽。激流和创造模式投掷保持原版行为。

## HUD

Chest Rig 自带 HUD，不需要也不兼容 Inventory HUD+。

- 27 格背包总览默认关闭，可显示在快捷栏上方，支持普通/迷你尺寸。
- 效果 HUD 取代右上角的原版效果图标，并显示剩余时间和等级。
- 防具和主手/计数器是独立面板，有各自开关，可分别移动。
- 按 `O` 修改 HUD 设置或编辑面板位置；效果和武器槽固定。
- 加载遮罩或世界加载界面出现时，HUD 会隐藏。

设置保存在 `config/arrowslot-hud.json`。

## 自动进食与拾取

- 饥饿值不高于三个图标时，胸挂自动进食，直到饥饿值不低于五个图标。
- 自动进食使用原版进食动作和移动减速，两次进食之间至少间隔 5 秒。
- 冷却期间受到伤害，会获得一次立即自动食用普通食物的机会；金苹果仍受自身 30/60 秒锁定限制。
- 安装 AppleSkin 后，生命值不高于三颗心时自动进食，直到 AppleSkin 预计生命值回满或饥饿值回满；未安装 AppleSkin 时该规则不生效，也不影响低饥饿自动进食。
- 多个食物槽都有食物时，会按优先级选择最合适的食物：低血量恢复时优先 AppleSkin 的预计恢复量，其余情况优先营养值和饱和度；正在物品冷却、金苹果锁定或当前无法食用的食物会被跳过。
- 拾取箭矢或食物时优先放入对应的未满槽位；其他物品只有在快捷栏和副手都没有空间时才进入通用槽。

### 树叶与苹果

使用非剪刀、非精准采集附魔的工具破坏树叶时，树叶掉落概率翻倍。这样掉落的苹果有 20% 概率为金苹果，2.5% 概率为附魔金苹果。

## 零耐久装备

盔甲、盾牌、分级武器/工具、弓、弩和三叉戟耐久归零后仍留在世界中，不会消失。

- 损坏的盔甲和盾牌失去护甲值和非负面附魔效果，也无法格挡；诅咒和经验修补仍然有效。
- 损坏的装备被取下后无法再次装备，可以通过铁砧、工作台或经验修补修复。
- 损坏的盾牌在下一次尝试格挡时被摧毁。
- 关闭 keepInventory 时，损坏的盔甲会在死亡时销毁；损坏的胸甲会掉落其中存放的内容物。开启 keepInventory 时，损坏的盔甲会保留，并获得持续 60 秒的绑定诅咒。
- 铁砧上用两个相同部件修复损坏装备时经验消耗翻倍；用钻石或下界合金锭修复消耗三倍材料。工作台合并两个相同的被追踪物品，会修复到剩余耐久之和的一半。

## 配置与常见问题

- **提示 Inventory HUD+ 互斥：** 从 `mods` 中移除 Inventory HUD+。
- **加载界面看不到 HUD：** 这是正常的，进入世界后会恢复。
- **HUD 位置不对：** 按 `O` 重置位置，或删除 `config/arrowslot-hud.json`。
- **更新后提示缺少类或 Mixin：** 执行 `gradle clean build` 并完全重启游戏。

## 从源码编译

- JDK 21
- Gradle 9.9.1 在 `PATH` 中；仓库不包含 wrapper
- 首次构建需要联网

```
gradle build
```

产物位于 `build/libs/chest_rig-1.21.1-neoforge-21.1.267-0.1.0-Alpha.jar`。怀疑旧输出时使用 `gradle clean build`。开发时可使用 `gradle runClient` 和 `gradle runServer`，运行目录位于 `run/` 下。
